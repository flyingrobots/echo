The original experiment files are absent. The reported timings and counts are source claims, not reproduced measurements.

## 2. Problem Description

Recovery caches a full WorldlineState for every distinct basis tick. Each cache miss replays from the initial boundary when no checkpoint exists. Consecutive bases repeat all earlier patches and retain growing graph and tick-history copies.

## 3. Proposed Solution

Process required coordinates in causal order with bounded replay state. Reuse verified prefixes. Preserve all basis, patch, receipt, decision, conflict, and initial-boundary checks.

## 4. Prerequisites

- [ ] Use the shared guarded Docker worker for executable checks.
- [ ] Record RED evidence before the code repair, or before/after evidence for a documentation repair.

No other PR must merge first. Execution order does not establish a dependency.

## 5. Scope

## 6. Acceptance Criteria

A multi-tick recovery witness counts applied replay patches and retained replay states. Applied replay-patch work grows with required history, not the sum of every prefix. Full replay snapshots stay bounded by worldline count. The witness accounts for their graph and tick-history data. Poisoned bases and reordered or incomplete outcomes still refuse.

## 7. Definition of Done
